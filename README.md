#  National Cyber Infrastructure — Network Health Monitor

A real-time network health and device monitoring dashboard designed for cybersecurity tracking, asset management, and threat mitigation simulation. Built for hackathons to provide a professional, government-portal-grade interface for monitoring connected nodes and identifying potential security risks (such as MITRE T1021 lateral movement vectors).

---

## 🚀 Features
- **Official Gov-Grade UI:** Designed with a secure dark-navy theme, grid borders, and standardized typography matching official national infrastructure dashboards.
- **Live Node Telemetry:** Simulates real-time tracking of connected IP addresses, MAC addresses, device categories, and bandwidth usage.
- **Dynamic Security Status:** Real-time flickering and alerts for SECURE vs. VULNERABLE network nodes.
- **Threat Intelligence & Mitigation:** Visual risk assessment indicators and actionable isolation protocols.

---

## 🛠️ Tech Stack
- **HTML5** (Semantic Structure)
- **CSS3** (Custom Styling & Grid Layouts)
- **JavaScript (ES6+)** (Dynamic Telemetry & Live Simulation Logic)
